# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Auto Window Size, please report it privately:

- **Email**: jujuawa@qq.com
- **GitHub**: [Open a private vulnerability report](https://github.com/3270728922/AutoWindowSize/security/advisories/new)

Please do **not** open a public GitHub issue for security vulnerabilities.

We will respond as soon as possible and work with you to resolve the issue.
