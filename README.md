# Auto Window Size

自动设置 Minecraft 游戏窗口大小的 Forge 模组。

## 功能

- 启动时自动把窗口设为配置大小并居中
- 锁定最小窗口尺寸，可以放大但不能缩得更小
- 配置值等于屏幕分辨率时自动全屏
- 退出全屏后自动恢复配置窗口大小
- 多显示器支持，自动检测窗口所在屏幕
- 按 O 键切换窗口锁定（默认开启）
- 屏幕分辨率过低时弹警告并退出
- 配置文件值越界自动钳位，不会崩

## 配置

配置文件路径：`config/autowindowsize-client.toml`

```toml
[window]
    width = 1440   # 窗口宽度，同时是最小宽度
    height = 810   # 窗口高度，同时是最小高度
```

## 按键

| 按键      | 功能             |
| --------- | ---------------- |
| O（默认） | 切换窗口大小锁定 |

可在游戏内 **选项 → 控制** 里修改按键。

## 环境要求

- Minecraft 1.20.1
- Forge 47.4+
- 客户端模组，服务端不需要装

## 制作目的

在玩模组整合包时，发现匠魂等模组的 GUI 在窗口缩得太小时会显示不全、按钮被挡住，而 Minecraft 本身又没有最小窗口限制。每次启动游戏都要手动拖窗口到合适大小，很麻烦。于是做了这个模组，启动时自动设置窗口大小、锁定最小窗口。
