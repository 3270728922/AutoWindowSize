## 制作目的

在制作整合包时，我经常遇到这样的问题：好不容易把各个模组的 UI 界面布局调试好了，结果玩家换了一个分辨率启动游戏，窗口大小变了，所有 UI 布局全乱了。

为了解决这个问题，我做了这个模组：启动时自动把窗口设置为指定大小并居中，同时锁定最小窗口尺寸，确保整合包的 UI 布局在不同玩家的电脑上都能保持一致。

---

## 功能特性

- **启动自动设置窗口大小**：启动游戏时自动将窗口设置为配置的分辨率，并在当前显示器上居中
- **锁定最小窗口尺寸**：锁定后窗口只能放大，不能缩小到配置尺寸以下，保证 UI 布局不被破坏
- **视频设置原生入口**：在「选项 → 视频设置」中原生插入「窗口设置」按钮，位于「全屏分辨率」下方，随列表滚动和 GUI 缩放正常布局
- **窗口设置界面**：独立的设置界面，可手动开关锁定，实时显示当前屏幕分辨率和游戏窗口分辨率
- **自定义按键切换**：可在控制设置中绑定按键，快速切换锁定状态（默认未绑定）
- **分辨率过低自动禁用**：当配置分辨率或硬编码最小分辨率高于玩家屏幕分辨率时，自动禁用锁定功能且不改动窗口大小，避免出现显示 bug
- **退出全屏恢复**：从全屏切换回窗口模式时，自动恢复配置的窗口大小并居中
- **进游戏状态提示**：每次进入世界时，聊天栏提示当前锁定状态（已锁定 / 已解锁 / 已禁用）
- **实时分辨率显示**：窗口设置界面实时显示当前屏幕分辨率和游戏窗口分辨率，拖动窗口后 1 秒自动刷新
- **多显示器支持**：自动检测游戏窗口所在的显示器，在对应显示器上居中

## 分辨率优先级

本模组的窗口尺寸遵循以下优先级（从高到低）：

```
代码硬编码最小值（1024×576）
        ↓
配置文件值（默认 1280×720，可修改）
        ↓
玩家手动拖动窗口大小（仅在锁定关闭时生效）
```

| 优先级 | 来源 | 默认值 | 说明 |
|--------|------|--------|------|
| 1（最高） | 代码硬编码 | 1024×576 | 写死在代码里的最小分辨率，16:9 比例，任何情况下都不会低于此值 |
| 2 | 配置文件 | 1280×720 | 在 `config/autowindowsize-client.toml` 中修改，启动时读取 |
| 3（最低） | 玩家手动拖动 | — | 仅在锁定功能关闭时，玩家可以自由拖动窗口边缘调整大小 |

> **注意**：锁定开启时，窗口的最小尺寸 = 配置文件值（但不低于硬编码最小值）。如果配置文件值低于 1024×576，则以 1024×576 为实际最小尺寸。

## 锁定机制详解

### 锁定开启时

- 窗口的**最小尺寸**被锁定为配置值（不低于 1024×576）
- 窗口**可以放大**，没有上限
- 窗口**不能缩小**到锁定尺寸以下
- 退出全屏时，自动恢复到配置尺寸并居中，同时重新应用最小尺寸限制

### 锁定关闭时

- 窗口大小**完全自由**，可以任意放大缩小
- 退出全屏时，恢复到配置尺寸并居中，但**不设置**最小尺寸限制
- 玩家可以通过界面按钮或自定义按键重新开启锁定

### 锁定被禁用时

- 锁定功能**完全不可用**，按钮灰色不可点击
- 窗口大小**不被改动**，保持玩家原来的大小
- 退出全屏时，**不改动**窗口大小
- 按自定义按键时，聊天栏提示"分辨率过低，锁定功能已禁用"
- 进入世界时，聊天栏提示禁用原因

## 分辨率过低检测

### 触发条件

当以下**任一条件**满足时，锁定功能自动禁用：

```
配置文件宽度 > 当前屏幕宽度
配置文件高度 > 当前屏幕高度
硬编码最小宽度(1024) > 当前屏幕宽度
硬编码最小高度(576) > 当前屏幕高度
```

### 触发后的行为

1. **不改动窗口大小**：保持玩家启动前的窗口大小，不强制设置为配置值
2. **不设置最小尺寸限制**：不调用 GLFW 的窗口尺寸限制
3. **自动关闭锁定**：`lockEnabled = false`
4. **标记为禁用**：`lockDisabled = true`
5. **进入世界时聊天栏提示**：红色文字说明禁用原因
6. **窗口设置界面按钮灰色**：显示"锁定已禁用（分辨率过低）"，不可点击
7. **按键触发时再次提示**：按切换锁定键时，聊天栏再次提示分辨率过低

### 恢复方法

将配置文件中的分辨率改为小于等于屏幕分辨率的值，然后**重启游戏**。

> 注意：检测在游戏启动时执行一次，运行中改变屏幕分辨率不会重新检测。

## 退出全屏行为

从全屏模式切换回窗口模式时（按 F11），模组的行为取决于当前锁定状态：

| 锁定状态 | 行为 |
|----------|------|
| 锁定开启 | 恢复配置窗口大小并居中，重新应用最小尺寸限制 |
| 锁定关闭 | 恢复配置窗口大小并居中，**不设置**最小尺寸限制 |
| 锁定禁用 | **不改动**窗口大小，保持退出全屏后的尺寸 |

---

## 进游戏状态提示

每次从主菜单或加载界面进入世界时，聊天栏会提示一次当前锁定状态：

| 状态 | 提示文字 | 颜色 |
|------|----------|------|
| 锁定开启 | `[AutoWindowSize] 已锁定最小窗口` | 绿色 |
| 锁定关闭 | `[AutoWindowSize] 已解锁窗口大小，可自由调整窗口大小` | 灰色 |
| 锁定禁用 | `[AutoWindowSize] 配置分辨率或最小分辨率高于屏幕分辨率，窗口锁定已自动禁用，窗口大小保持不变` | 红色 |

- 每次进入世界只提示**一次**
- 退回主菜单后再次进入世界，会**再次提示**
- 提示输出在聊天栏，不是标题/副标题

## 窗口设置界面

### 打开方式

1. 主菜单：`选项...` → `视频设置...` → 点击 `窗口设置` 按钮
2. 游戏中：`Esc` → `选项...` → `视频设置...` → 点击 `窗口设置` 按钮

> 「窗口设置」按钮原生插入在视频设置列表的「全屏分辨率」行下方，随列表滚动和 GUI 缩放正常布局。

### 界面内容

| 元素 | 说明 |
|------|------|
| 屏幕分辨率 | 当前主显示器的分辨率（如 1920 × 1080），白色文字 |
| 游戏分辨率 | 当前游戏窗口的 framebuffer 像素尺寸（如 1280 × 720），浅绿色文字 |
| 窗口锁定按钮 | 点击切换锁定开启/关闭；锁定禁用时灰色不可点击 |
| 完成按钮 | 返回视频设置界面 |

### 实时刷新机制

- 打开界面时，读取一次当前窗口分辨率
- 拖动窗口边缘改变大小时，界面显示橙色提示：`窗口尺寸变化中，松开后 1 秒自动刷新…`
- 停止拖动满 **1 秒**后，自动更新「游戏分辨率」数值
- 延迟刷新是为了避免拖动过程中频繁重绘文字导致卡顿

## 安装方法

1. 确保已安装 Minecraft 1.20.1 和 Forge 47.x
2. 将模组 jar 文件放入 `.minecraft/mods` 文件夹
3. 启动游戏即可

> 本模组为**客户端模组**，不需要安装在服务端。

## 配置文件

### 文件路径

```
.minecraft/config/autowindowsize-client.toml
```

### 配置项

```toml
[window]
    # 启动窗口宽度，也是锁定时的最小宽度
    # 范围：1 ~ 7680
    # 默认：1280
    width = 1280

    # 启动窗口高度，也是锁定时的最小高度
    # 范围：1 ~ 4320
    # 默认：720
    height = 720
```

### 注意事项

- 配置值在游戏**启动时**读取，运行中修改配置文件不会立即生效，需要重启游戏
- 配置值低于硬编码最小值（1024×576）时，实际最小锁定尺寸仍为 1024×576
- 配置值高于屏幕分辨率时，锁定功能自动禁用，窗口大小不被改动

## 键位绑定

### 默认状态

**未绑定**。模组不会占用任何按键，玩家需要自行在控制设置中绑定。

### 绑定方法

1. `选项...` → `控制...`
2. 搜索「自动窗口大小」或滚动找到「自动窗口大小」分类
3. 点击「切换窗口大小锁定」
4. 按下你想绑定的键（可以是键盘键或鼠标键）
5. 点击「完成」保存

### 使用方法

- 在游戏中（世界内）按下绑定的键，切换锁定开启/关闭
- 聊天栏会提示切换后的状态
- 锁定被禁用时，按键不会切换状态，而是提示分辨率过低

---

## 多显示器支持

- 模组启动时自动检测游戏窗口**当前所在的显示器**（根据窗口中心点判断）
- 在对应显示器上居中窗口，而不是总是在主显示器居中
- 跨屏拖动窗口时（窗口中心在两个显示器之间），默认使用主显示器
- 获取当前显示器分辨率时，也使用窗口所在显示器的分辨率，而不是主显示器

## 常见问题

**Q：为什么我改了配置文件的分辨率，启动后窗口没变？**
A：如果配置的分辨率高于你的屏幕分辨率，模组会自动禁用锁定且不改动窗口大小。请将配置值改为小于等于屏幕分辨率的值，然后重启游戏。

**Q：锁定后窗口还能放大吗？**
A：可以。锁定只限制最小尺寸，不限制最大尺寸，你可以随意放大窗口。

**Q：怎么自定义切换锁定的按键？**
A：`选项...` → `控制...` → 搜索「自动窗口大小」→ 点击「切换窗口大小锁定」→ 按下你想绑定的键。默认未绑定。

**Q：支持多显示器吗？**
A：支持。模组会自动检测游戏窗口所在的显示器，并在对应显示器上居中。

**Q：为什么窗口设置界面的游戏分辨率不实时更新？**
A：为了避免拖动窗口时频繁重绘导致卡顿，模组会在你停止拖动满 1 秒后才更新数值。拖动中会显示橙色提示。

**Q：锁定被禁用了怎么恢复？**
A：将配置文件中的分辨率改为小于等于屏幕分辨率的值，然后重启游戏。锁定禁用只在启动时检测，运行中不会自动恢复。

**Q：这个模组需要安装在服务端吗？**
A：不需要。这是纯客户端模组，只影响客户端的窗口大小，服务端不需要安装。

**Q：和其他模组冲突吗？**
A：本模组只修改游戏窗口的大小和最小尺寸限制，不修改游戏内任何机制，一般不会和其他模组冲突。如果和其他修改窗口大小的模组同时使用，可能会有冲突。
