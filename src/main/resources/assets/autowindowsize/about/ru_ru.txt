Auto Window Size (Автоматический размер окна)

【Назначение】
При создании модпака вы тратите много времени на идеальную настройку GUI, HUD и интерфейсов. Но когда игроки запускают игру на разных мониторах или разрешениях, размер окна меняется и все макеты ломаются. Этот мод решает эту проблему: превращает "размер игрового окна" из случайного события в управляемый, воспроизводимый и ограниченный выбор. Его функциональность намеренно минимальна — он работает только с окном на уровне операционной системы, не изменяет масштаб GUI и не затрагивает никакой внутриигровой рендеринг или игровую логику, поэтому почти никогда не конфликтует с другими модами.

【Описание MOD】
Лёгкий клиентский мод, который автоматически изменяет размер, центрирует и блокирует игровое окно Minecraft, сохраняя тщательно настроенные макеты UI модпака согласованными на компьютере каждого игрока.
Основные функции: автоматическое изменение размера окна при запуске, 128 предустановок разрешения (сгруппированы по 8 соотношениям сторон), блокировка минимального размера, фиксированный размер окна, центрирование в один клик, автоматический полноэкранный/развёрнутый/безрамочный режим при запуске, запоминание позиции окна, окно всегда поверх (3 режима: выкл/стандартный/принудительный), безрамочный режим окна (3 состояния: оконный/развёрнутый/полноэкранный), кнопка цикла состояния окна, 17 клиентских команд /aws, 5 настраиваемых горячих клавиш, поддержка нескольких мониторов, отображение разрешения в реальном времени, режим отладочного журнала и т.д. Поддерживает 20 языков.

【Способ использования】
1、После установки мода и запуска игры нажмите кнопку "Управление окнами и настройка разрешения" в "Настройках специальных возможностей", чтобы открыть интерфейс конфигурации, или используйте команду /aws gui.
2、Настройте различные параметры в интерфейсе конфигурации: размер окна, блокировка минимального размера, фиксированный размер окна, автоматический полноэкранный/развёрнутый/безрамочный режим, окно всегда поверх, безрамочный режим и т.д.
3、Предустановки разрешения: используйте стрелки влево/вправо селектора соотношения сторон для переключения между 16:9, 16:10, 4:3, 5:4, 21:9, 3:2, 2:1, 9:16 и Пользовательское. В центре отображается текущее соотношение и разрешение окна в реальном времени, а ниже отображаются 16 кнопок предустановок для соответствующего соотношения. Нажмите, чтобы одним кликом изменить размер окна и центрировать его.
4、Пользовательское разрешение: после переключения на соотношение "Пользовательское" введите ширину и высоту в поля ввода, нажмите кнопку "Применить" или клавишу Enter. Кнопка "Применить" отключается с подсказкой, когда введённое значение выходит за пределы диапазона.
5、Горячие клавиши: назначьте клавиши для "Открыть настройки Auto Window Size", "Центрировать окно", "Переключить безрамочный режим", "Цикл состояния окна" и "Переключить окно всегда поверх" в "Настройках управления". По умолчанию не назначены.
6、Команды: введите /aws help, чтобы просмотреть постраничный полный список команд (всего 3 страницы, по 8 команд на странице).
7、Файлы конфигурации: config/AutoWindowSize/config.toml (основная конфигурация) и config/AutoWindowSize/window.json (сохранённая позиция окна).

【Команды】
Все команды начинаются с /aws. Введите /aws help в игре, чтобы просмотреть постраничный полный список команд.
Распространённые команды:
· /aws help [страница] - Показать список команд (3 страницы, по 8 на странице)
· /aws gui - Открыть интерфейс управления окнами и настройки разрешения
· /aws about - Открыть страницу "О моде"
· /aws info - Показать текущую информацию об окне, конфигурации и разрешении
· /aws version - Показать информацию о версии мода
· /aws config - Открыть папку конфигурации
· /aws status - Проверить статус блокировки минимального размера
· /aws toggle [true/false] - Переключить блокировку минимального размера
· /aws fixed [true/false] - Переключить фиксированный размер окна
· /aws center - Центрировать окно на текущем мониторе
· /aws fullscreen [true/false] - Переключить текущий полноэкранный режим
· /aws maximize [true/false] - Переключить текущее развёрнутое состояние
· /aws remember [true/false] - Переключить запоминание позиции окна
· /aws top [off/normal/force] - Цикл или прямое переключение режима "всегда поверх"
· /aws debug [true/false] - Переключить отладочный журнал
· /aws borderless [true/false] - Переключить безрамочный режим
· /aws borderless auto [true/false] - Переключить автоматический безрамочный режим при запуске
· /aws resolution [соотношение] <пресет> - Применить разрешение и центрировать, поддерживает автодополнение Tab

【Горячие клавиши】
Все горячие клавиши по умолчанию не назначены. Настройте их в "Параметры → Управление → Auto Window Size". При нажатии любой горячей клавиши в чате появляется обратная связь.
· Открыть настройки Auto Window Size - Открыть интерфейс управления окнами и настройки разрешения
· Центрировать окно - Центрировать окно на текущем мониторе
· Переключить безрамочный режим - Включить/выключить безрамочный режим
· Цикл состояния окна - Цикл между оконным → развёрнутым → полноэкранным
· Переключить окно всегда поверх - Цикл режима "всегда поверх" (выкл → стандартный → принудительный)

【Примечания】
· Автоматическая миграция конфигурации: начиная с v1.1.1, при обновлении мод автоматически обнаруживает и переносит старые файлы конфигурации при первом запуске. Не нужно вручную удалять папку конфигурации. После входа в мир в чате появится уведомление о завершении миграции.
· Мод только для клиента: нужно устанавливать только на клиент, не нужно на сервер.
· Поддержка платформ: поддерживается только настольная Java Edition (Windows / macOS / Linux), не поддерживается мобильная / Bedrock Edition.
· Безрамочное окно и Windows Snap: в текущей версии функция Windows Snap (прикрепление окон) может иметь проблемы совместимости в безрамочном оконном режиме. Временное решение: сначала отключите блокировку минимального размера, используйте Windows Snap для настройки окна, затем снова включите блокировку.
· Примечание о принудительном режиме "всегда поверх": принудительный режим всегда остаётся поверх окон "всегда поверх" того же уровня и не перекрывается ими, но не будет выше окон "всегда поверх" на системном уровне (например, диспетчер задач).
