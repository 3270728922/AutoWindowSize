Auto Window Size (Ukuran Jendela Otomatis)

【Tujuan】
Saat membuat modpack, Anda menghabiskan banyak waktu untuk menyempurnakan GUI, HUD, dan antarmuka. Namun ketika pemain memulai permainan di monitor atau resolusi yang berbeda, ukuran jendela berubah dan semua tata letak rusak. Mod ini menyelesaikan masalah tersebut: ia mengubah "ukuran jendela permainan" dari peristiwa acak menjadi pilihan yang dapat dikontrol, dapat diulang, dan terbatas. Cakupannya sengaja dibuat minimal — ia hanya bekerja dengan jendela di tingkat sistem operasi, tidak mengubah skala GUI, dan tidak menyentuh rendering dalam permainan atau logika permainan apa pun,因此 ia hampir tidak pernah bertentangan dengan mod lain.

【Presentasi MOD】
Mod ringan sisi klien yang secara otomatis mengubah ukuran, memusatkan, dan mengunci jendela permainan Minecraft, menjaga tata letak UI modpack yang telah Anda sesuaikan dengan cermat tetap konsisten di komputer setiap pemain.
Fitur utama: pengubahan ukuran jendela otomatis saat startup, 128 prasetel resolusi (dikelompokkan berdasarkan 8 rasio aspek), kunci ukuran minimum, ukuran jendela tetap, pemusatan dengan satu klik, layar penuh/maksimalkan/tanpa bingkai otomatis saat startup, memori posisi jendela, jendela selalu di depan (3 mode: mati/standar/paksa), mode jendela tanpa bingkai (3 status: jendela/dimaksimalkan/layar penuh), tombol siklus status jendela, 17 perintah klien /aws, 5 pintasan keyboard yang dapat disesuaikan, dukungan multi-monitor, tampilan resolusi waktu nyata, mode log debug, dll. Mendukung 20 bahasa.

【Cara Penggunaan】
1、Setelah menginstal mod dan memulai permainan, klik tombol "Manajemen jendela dan pengaturan resolusi" di "Pengaturan Aksesibilitas" untuk membuka antarmuka konfigurasi, atau gunakan perintah /aws gui.
2、Sesuaikan berbagai pengaturan di antarmuka konfigurasi: ukuran jendela, kunci ukuran minimum, ukuran jendela tetap, layar penuh/maksimalkan/tanpa bingkai otomatis, jendela selalu di depan, mode tanpa bingkai, dll.
3、Prasetel resolusi: gunakan panah kiri/kanan pemilih rasio aspek untuk beralih antara 16:9, 16:10, 4:3, 5:4, 21:9, 3:2, 2:1, 9:16 dan Kustom. Di tengah menampilkan rasio saat ini dan resolusi jendela waktu nyata, dan di bawahnya menampilkan 16 tombol prasetel untuk rasio yang sesuai. Klik untuk menyesuaikan ukuran jendela dan memusatkannya dengan satu klik.
4、Resolusi kustom: setelah beralih ke rasio "Kustom", masukkan lebar dan tinggi di kolom input, klik tombol "Terapkan" atau tekan tombol Enter. Tombol Terapkan dinonaktifkan dengan tooltip ketika nilai input berada di luar rentang.
5、Pintasan keyboard: tetapkan tombol untuk "Buka pengaturan Auto Window Size", "Pusatkan jendela", "Beralih tanpa bingkai", "Siklus status jendela", dan "Beralih jendela selalu di depan" di "Pengaturan Kontrol". Tidak ditetapkan secara default.
6、Perintah: ketik /aws help untuk melihat daftar perintah lengkap yang dipaginasi (total 3 halaman, 8 perintah per halaman).
7、File konfigurasi: config/AutoWindowSize/config.toml (konfigurasi utama) dan config/AutoWindowSize/window.json (posisi jendela yang disimpan).

【Perintah】
Semua perintah dimulai dengan /aws. Ketik /aws help dalam permainan untuk melihat daftar perintah lengkap yang dipaginasi.
Perintah umum:
· /aws help [halaman] - Tampilkan daftar perintah (3 halaman, 8 per halaman)
· /aws gui - Buka antarmuka manajemen jendela dan pengaturan resolusi
· /aws about - Buka halaman Tentang
· /aws info - Tampilkan informasi jendela, konfigurasi, dan resolusi saat ini
· /aws version - Tampilkan informasi versi mod
· /aws config - Buka folder konfigurasi
· /aws status - Periksa status kunci ukuran minimum
· /aws toggle [true/false] - Beralih kunci ukuran minimum
· /aws fixed [true/false] - Beralih ukuran jendela tetap
· /aws center - Pusatkan jendela di monitor saat ini
· /aws fullscreen [true/false] - Beralih status layar penuh saat ini
· /aws maximize [true/false] - Beralih status dimaksimalkan saat ini
· /aws remember [true/false] - Beralih memori posisi jendela
· /aws top [off/normal/force] - Siklus atau atur langsung mode selalu di depan
· /aws debug [true/false] - Beralih log debug
· /aws borderless [true/false] - Beralih mode tanpa bingkai
· /aws borderless auto [true/false] - Beralih mode tanpa bingkai otomatis saat startup
· /aws resolution [rasio] <prasetel> - Terapkan resolusi dan pusatkan, mendukung pelengkapan otomatis Tab

【Pintasan Keyboard】
Semua pintasan keyboard tidak ditetapkan secara default. Atur di "Opsi → Kontrol → Auto Window Size". Saat menekan pintasan apa pun, umpan balik diberikan di obrolan.
· Buka pengaturan Auto Window Size - Buka antarmuka manajemen jendela dan pengaturan resolusi
· Pusatkan jendela - Pusatkan jendela di monitor saat ini
· Beralih tanpa bingkai - Nyalakan/matikan mode tanpa bingkai
· Siklus status jendela - Siklus antara jendela → dimaksimalkan → layar penuh
· Beralih jendela selalu di depan - Siklus mode selalu di depan (mati → standar → paksa)

【Catatan】
· Migrasi konfigurasi otomatis: sejak v1.1.1, saat memperbarui, mod secara otomatis mendeteksi dan memigrasikan file konfigurasi lama pada startup pertama. Anda tidak perlu menghapus folder konfigurasi secara manual. Setelah memasuki dunia, obrolan akan memberi tahu penyelesaian migrasi.
· Hanya mod sisi klien: hanya perlu diinstal pada klien, bukan pada server.
· Dukungan platform: hanya mendukung Java Edition desktop (Windows / macOS / Linux), tidak mendukung edisi seluler / Bedrock.
· Jendela tanpa bingkai dan Windows Snap: di versi saat ini, fungsi Windows Snap (jendela snap) mungkin memiliki masalah kompatibilitas dalam mode jendela tanpa bingkai. Solusi sementara: nonaktifkan dulu kunci ukuran minimum, gunakan Windows Snap untuk menyesuaikan jendela, lalu aktifkan kembali kuncinya.
· Catatan tentang selalu di depan paksa: mode paksa selalu tetap di depan di antara jendela selalu di depan tingkat yang sama dan tidak akan ditutupi oleh mereka, tetapi tidak akan lebih tinggi dari jendela selalu di depan tingkat sistem (misalnya, Pengelola Tugas).
