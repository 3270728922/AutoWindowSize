Auto Window Size（自动窗口大小）

【制作目的】
制作整合包时，你花了大量时间把 GUI、HUD 和交互界面调整到恰到好处。但玩家在不同显示器或分辨率下启动游戏时，窗口大小一变，所有布局都乱了。这个模组就是为了解决这个问题：把"游戏窗口大小"从随机事件变成可控、可重复、受约束的选择。它的功能范围刻意保持精简，只操作操作系统层面的窗口本身，不改变 GUI 缩放，不触碰任何游戏内渲染或游戏逻辑，因此几乎不会与其他模组冲突。

【MOD 介绍】
一个轻量级的客户端模组，自动调整、居中和锁定 Minecraft 游戏窗口，让精心调校的整合包 UI 布局在每台玩家的电脑上都保持一致。
核心功能包括：启动时自动调整窗口大小、128 个分辨率预设（按 8 种宽高比分组）、最小尺寸锁定、固定窗口大小、一键居中、启动自动全屏/最大化/无边框、窗口位置记忆、窗口置顶（关闭/标准置顶/强制置顶三档）、无边框窗口模式（窗口化/最大化/全屏三种状态）、窗口状态循环按钮、17 个 /aws 客户端命令、5 个可自定义快捷键、多显示器感知、实时分辨率显示、调试日志模式等。支持 20 种语言。

【使用方法】
1、安装模组后启动游戏，在"辅助功能设置"中点击"窗口管理与分辨率设置"按钮打开配置界面，或使用 /aws gui 命令。
2、在配置界面中调整各项设置：窗口大小、最小尺寸锁定、固定窗口大小、自动全屏/最大化/无边框、窗口置顶、无边框模式等。
3、分辨率预设：使用比例选择器左右箭头在 16:9、16:10、4:3、5:4、21:9、3:2、2:1、9:16、自定义之间切换，中间显示当前比例与窗口实时分辨率，下方显示对应比例的 16 个预设按钮，点击即可一键调整窗口大小并居中。
4、自定义分辨率：切换到"自定义"比例后，在输入框中输入宽高，点击"应用"按钮或按回车键即可。输入值超出范围时应用按钮会禁用并提示。
5、快捷键：在"控制设置"中为"打开 Auto Window Size 设置"、"居中窗口"、"切换无边框"、"循环窗口状态"、"切换窗口置顶"绑定快捷键，默认未绑定。
6、命令：输入 /aws help 查看分页的完整命令列表（共3页，每页8条）。
7、配置文件：config/AutoWindowSize/config.toml（主配置）和 config/AutoWindowSize/window.json（保存的窗口位置）。

【指令】
所有指令均以 /aws 开头，在游戏内输入 /aws help 可查看分页的完整指令列表。
常用指令：
· /aws help [页码] - 显示指令列表（共3页，每页8条）
· /aws gui - 打开窗口管理与分辨率设置界面
· /aws about - 打开关于页面
· /aws info - 显示当前窗口、配置与分辨率信息
· /aws version - 显示模组版本信息
· /aws config - 打开配置文件夹
· /aws status - 查看最小尺寸锁定状态
· /aws toggle [true/false] - 切换最小尺寸锁定
· /aws fixed [true/false] - 切换固定窗口大小
· /aws center - 在当前显示器上居中窗口
· /aws fullscreen [true/false] - 切换当前全屏状态
· /aws maximize [true/false] - 切换当前最大化状态
· /aws remember [true/false] - 切换窗口位置记忆
· /aws top [off/normal/force] - 循环或直接切换窗口置顶模式
· /aws debug [true/false] - 切换调试日志
· /aws borderless [true/false] - 切换无边框模式
· /aws borderless auto [true/false] - 切换启动自动无边框
· /aws resolution [比例] <预设> - 应用分辨率并居中，支持 Tab 自动补全

【快捷键】
所有快捷键默认未绑定，在"选项 → 控制 → Auto Window Size"中设置。按下时都会在聊天框给出反馈。
· 打开 Auto Window Size 设置 - 打开窗口管理与分辨率设置界面
· 居中窗口 - 在当前显示器上居中窗口
· 切换无边框 - 切换无边框模式开/关
· 循环窗口状态 - 在窗口化 → 最大化 → 全屏之间循环
· 切换窗口置顶 - 循环切换窗口置顶模式（关闭→标准置顶→强制置顶）

【注意事项】
· 配置自动迁移：从 v1.1.1 开始，升级时模组会在首次启动时自动检测并迁移旧配置文件，无需手动删除配置文件夹，进入世界后聊天框会提示迁移完成。
· 纯客户端模组：仅需安装在客户端，无需安装在服务端。
· 平台支持：仅支持桌面 Java 版（Windows / macOS / Linux），不支持手机版 / 基岩版。
· 窗口化无边框与 Windows 分屏：当前版本窗口化无边框模式下，Windows 分屏（Snap）功能可能存在兼容性问题。临时解决方法：先取消最小尺寸锁定，使用 Windows 分屏调整窗口后再重新开启锁定。
· 强制置顶说明：强制置顶模式在同级置顶窗口中始终保持在最前，不会被同级置顶窗口覆盖，但不会高于系统级置顶窗口（如任务管理器）。
