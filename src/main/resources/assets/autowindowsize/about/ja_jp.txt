Auto Window Size（自動ウィンドウサイズ）

【制作目的】
モッドパックを作るとき、GUI、HUD、インターフェースを完璧に調整するのに多くの時間を費やします。しかし、プレイヤーが異なるモニターや解像度でゲームを起動すると、ウィンドウサイズが変わってレイアウトがすべて崩れてしまいます。このモッドはその問題を解決するためのものです：「ゲームウィンドウサイズ」をランダムなイベントから、制御可能で再現可能で制約された選択肢に変えます。機能範囲は意図的に最小限に抑えられており、OSレベルのウィンドウ自体のみを操作し、GUIスケールを変更せず、ゲーム内レンダリングやゲームロジックには一切触れないため、他のモッドと競合することはほとんどありません。

【MOD 紹介】
Minecraft ゲームウィンドウを自動的にリサイズ、センタリング、ロックする軽量なクライアント側モッドで、慎重に調整されたモッドパックの UI レイアウトをすべてのプレイヤーのコンピュータで一貫して保ちます。
主な機能：起動時の自動ウィンドウサイズ調整、128個の解像度プリセット（8種類のアスペクト比でグループ化）、最小サイズロック、ウィンドウサイズ固定、ワンクリックセンタリング、起動時の自動フルスクリーン/最大化/ボーダーレス、ウィンドウ位置記憶、ウィンドウ最前面（オフ/標準最前面/強制最前面の3段階）、ボーダーレスウィンドウモード（ウィンドウ/最大化/フルスクリーンの3状態）、ウィンドウ状態サイクルボタン、17個の /aws クライアントコマンド、5個のカスタマイズ可能なキーバインド、マルチモニター対応、リアルタイム解像度表示、デバッグログモードなど。20言語に対応。

【使用方法】
1、モッドをインストールしてゲームを起動し、「アクセシビリティ設定」の「ウィンドウ管理と解像度設定」ボタンをクリックして設定画面を開くか、/aws gui コマンドを使用します。
2、設定画面で各種設定を調整：ウィンドウサイズ、最小サイズロック、ウィンドウサイズ固定、自動フルスクリーン/最大化/ボーダーレス、ウィンドウ最前面、ボーダーレスモードなど。
3、解像度プリセット：アスペクト比セレクターの左右矢印で 16:9、16:10、4:3、5:4、21:9、3:2、2:1、9:16、カスタム を切り替え、中央に現在の比率とウィンドウのリアルタイム解像度が表示され、下に対応する比率の16個のプリセットボタンが表示されます。クリックするとワンクリックでウィンドウサイズを調整してセンタリングします。
4、カスタム解像度：「カスタム」比率に切り替えた後、入力ボックスに幅と高さを入力し、「適用」ボタンをクリックするか Enter キーを押します。入力値が範囲外の場合、適用ボタンは無効になりヒントが表示されます。
5、キーバインド：「コントロール設定」で「Auto Window Size 設定を開く」、「ウィンドウをセンタリング」、「ボーダーレスを切り替え」、「ウィンドウ状態をサイクル」、「ウィンドウ最前面を切り替え」にキーを割り当てます。デフォルトでは未割り当てです。
6、コマンド：/aws help と入力すると、ページ分割された完全なコマンドリストが表示されます（全3ページ、各ページ8件）。
7、設定ファイル：config/AutoWindowSize/config.toml（メイン設定）と config/AutoWindowSize/window.json（保存されたウィンドウ位置）。

【コマンド】
すべてのコマンドは /aws で始まります。ゲーム内で /aws help と入力すると、ページ分割された完全なコマンドリストが表示されます。
よく使うコマンド：
· /aws help [ページ] - コマンドリストを表示（全3ページ、各ページ8件）
· /aws gui - ウィンドウ管理と解像度設定画面を開く
· /aws about - バージョン情報ページを開く
· /aws info - 現在のウィンドウ、設定、解像度情報を表示
· /aws version - モッドのバージョン情報を表示
· /aws config - 設定フォルダを開く
· /aws status - 最小サイズロックの状態を確認
· /aws toggle [true/false] - 最小サイズロックを切り替え
· /aws fixed [true/false] - ウィンドウサイズ固定を切り替え
· /aws center - 現在のモニターでウィンドウをセンタリング
· /aws fullscreen [true/false] - 現在のフルスクリーン状態を切り替え
· /aws maximize [true/false] - 現在の最大化状態を切り替え
· /aws remember [true/false] - ウィンドウ位置記憶を切り替え
· /aws top [off/normal/force] - ウィンドウ最前面モードをサイクルまたは直接切り替え
· /aws debug [true/false] - デバッグログを切り替え
· /aws borderless [true/false] - ボーダーレスモードを切り替え
· /aws borderless auto [true/false] - 起動時の自動ボーダーレスを切り替え
· /aws resolution [比率] <プリセット> - 解像度を適用してセンタリング、Tab 自動補完に対応

【キーバインド】
すべてのキーバインドはデフォルトで未割り当てです。「オプション → コントロール → Auto Window Size」で設定します。押すとチャット欄にフィードバックが表示されます。
· Auto Window Size 設定を開く - ウィンドウ管理と解像度設定画面を開く
· ウィンドウをセンタリング - 現在のモニターでウィンドウをセンタリング
· ボーダーレスを切り替え - ボーダーレスモードのオン/オフを切り替え
· ウィンドウ状態をサイクル - ウィンドウ → 最大化 → フルスクリーン をサイクル
· ウィンドウ最前面を切り替え - ウィンドウ最前面モードをサイクル（オフ→標準最前面→強制最前面）

【注意事項】
· 設定の自動移行：v1.1.1 以降、アップグレード時にモッドが初回起動時に古い設定ファイルを自動的に検出して移行します。設定フォルダを手動で削除する必要はなく、ワールドに入るとチャット欄に移行完了が通知されます。
· クライアント専用モッド：クライアントへのインストールのみが必要で、サーバーへのインストールは不要です。
· プラットフォーム対応：デスクトップ Java 版（Windows / macOS / Linux）のみ対応し、モバイル版 / 統合版には対応しません。
· ウィンドウボーダーレスと Windows スナップ：現在のバージョンでは、ウィンドウボーダーレスモードで Windows スナップ（ウィンドウスナップ）機能に互換性の問題が生じる可能性があります。一時的な解決方法：まず最小サイズロックを解除し、Windows スナップでウィンドウを調整してからロックを再び有効にします。
· 強制最前面の説明：強制最前面モードは同レベルの最前面ウィンドウの中で常に最前に保たれ、同レベルの最前面ウィンドウに覆われることはありませんが、システムレベルの最前面ウィンドウ（タスクマネージャーなど）より上になることはありません。
