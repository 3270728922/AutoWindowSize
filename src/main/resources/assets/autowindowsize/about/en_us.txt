Auto Window Size

[Purpose]
When making modpacks, you spend hours tuning GUIs, HUDs and interfaces. But when players launch on different monitors or resolutions, the window size changes and all layouts break. This mod solves that: turns "game window size" from a random event into a controllable, repeatable, constrained choice. It only manipulates the OS-level window itself, never changes GUI scale, never touches in-game rendering or logic, so it almost never conflicts with other mods.

[About]
A lightweight client mod that auto-resizes, centers and locks the Minecraft game window, keeping carefully tuned modpack UI layouts consistent on every player's PC.
Features: auto window size on launch, 128 resolution presets (grouped by 8 aspect ratios), minimum-size lock, fixed window size, one-click center, auto fullscreen/maximize/borderless on launch, window position memory, always-on-top (3 modes: off/normal/force), borderless mode (windowed/maximized/fullscreen), window state cycle button, 17 /aws client commands, 5 customizable keybinds, multi-monitor awareness, real-time resolution display, debug log mode. Supports 20 languages.

[Usage]
1. Install and launch. Click "Window Management & Resolution Settings" in Accessibility Settings, or use /aws gui.
2. Adjust settings: window size, minimum-size lock, fixed size, auto fullscreen/maximize/borderless, always-on-top, borderless mode.
3. Resolution presets: use left/right arrows to switch between 16:9, 16:10, 4:3, 5:4, 21:9, 3:2, 2:1, 9:16, Custom. Center shows current ratio and real-time window resolution. Below are 16 preset buttons, click to resize and center.
4. Custom resolution: switch to "Custom" ratio, enter width and height, click "Apply" or press Enter. Apply button disables when out of range.
5. Keybinds: bind in Controls Settings for "Open Auto Window Size Settings", "Center Window", "Toggle Borderless", "Cycle Window State", "Toggle Always-on-Top". Unbound by default.
6. Commands: type /aws help for paginated command list (3 pages, 8 per page).
7. Config files: config/AutoWindowSize/config.toml (main) and config/AutoWindowSize/window.json (saved window position).

[Commands]
All commands start with /aws. Type /aws help for full paginated list.
Common commands:
- /aws help [page] - Show command list (3 pages, 8 per page)
- /aws gui - Open Window Management & Resolution Settings
- /aws about - Open About page
- /aws info - Show current window, config and resolution info
- /aws version - Show mod version info
- /aws config - Open config folder
- /aws status - Check minimum-size lock status
- /aws toggle [true/false] - Toggle minimum-size lock
- /aws fixed [true/false] - Toggle fixed window size
- /aws center - Center window on current monitor
- /aws fullscreen [true/false] - Toggle current fullscreen state
- /aws maximize [true/false] - Toggle current maximized state
- /aws remember [true/false] - Toggle window position memory
- /aws top [off/normal/force] - Cycle or set always-on-top mode
- /aws debug [true/false] - Toggle debug log
- /aws borderless [true/false] - Toggle borderless mode
- /aws borderless auto [true/false] - Toggle auto borderless on launch
- /aws resolution [ratio] <preset> - Apply resolution and center, Tab-completion supported

[Keybinds]
All unbound by default. Set in Options > Controls > Auto Window Size. Pressing gives chat feedback.
- Open Auto Window Size Settings - Open settings screen
- Center Window - Center on current monitor
- Toggle Borderless - Toggle borderless mode on/off
- Cycle Window State - Cycle windowed > maximized > fullscreen
- Toggle Always-on-Top - Cycle always-on-top (off > normal > force)

[Notes]
- Config auto-migration: Since v1.1.1, the mod auto-detects and migrates old config on first launch after upgrade. No need to manually delete config folder. Chat will notify when migration completes.
- Client-only mod: Only needs to be installed on client, not server.
- Platform support: Desktop Java Edition only (Windows / macOS / Linux). No mobile / Bedrock.
- Windowed borderless & Windows Snap: Current version may have compatibility issues with Windows Snap in windowed borderless mode. Workaround: disable minimum-size lock first, use Windows Snap to adjust, then re-enable lock.
- Force always-on-top: Force mode stays on top among same-level always-on-top windows, but will not be higher than system-level always-on-top windows (e.g. Task Manager).
