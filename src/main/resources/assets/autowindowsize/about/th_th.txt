Auto Window Size (ขนาดหน้าต่างอัตโนมัติ)

【วัตถุประสงค์】
เมื่อคุณทำ modpack คุณใช้เวลามากในการปรับแต่ง GUI, HUD และอินเทอร์เฟซให้สมบูรณ์แบบ แต่เมื่อผู้เล่นเปิดเกมบนจอภาพหรือความละเอียดที่แตกต่างกัน ขนาดหน้าต่างจะเปลี่ยนไปและเลย์เอาต์ทั้งหมดจะเสียหาย mod นี้แก้ปัญหานี้: มันเปลี่ยน "ขนาดหน้าต่างเกม" จากเหตุการณ์สุ่มให้กลายเป็นทางเลือกที่ควบคุมได้ ทำซ้ำได้ และมีข้อจำกัด ขอบเขตของมันถูกเก็บไว้ให้น้อยที่สุดโดยเจตนา — มันทำงานเฉพาะกับหน้าต่างในระดับระบบปฏิบัติการ ไม่เปลี่ยนมาตราส่วน GUI และไม่แตะต้องการเรนเดอร์ในเกมหรือตรรกะเกมใดๆ ดังนั้นมันจึงแทบไม่เคยขัดแย้งกับ mod อื่นๆ

【แนะนำ MOD】
mod ที่เบาบางด้านไคลเอนต์ซึ่งปรับขนาด จัดกึ่งกลาง และล็อกหน้าต่างเกม Minecraft โดยอัตโนมัติ ทำให้เลย์เอาต์ UI ของ modpack ที่คุณปรับแต่งอย่างรอบคอบยังคงสอดคล้องกันบนคอมพิวเตอร์ของผู้เล่นทุกคน
คุณสมบัติหลัก: ปรับขนาดหน้าต่างอัตโนมัติเมื่อเปิดตัว, 128 ค่าล่วงหน้าความละเอียด (จัดกลุ่มตาม 8 อัตราส่วนภาพ), ล็อกขนาดขั้นต่ำ, ขนาดหน้าต่างคงที่, จัดกึ่งกลางด้วยคลิกเดียว, เต็มหน้าจอ/ขยายสูงสุด/ไร้กรอบอัตโนมัติเมื่อเปิดตัว, หน่วยความจำตำแหน่งหน้าต่าง, หน้าต่างอยู่บนสุดเสมอ (3 โหมด: ปิด/มาตรฐาน/บังคับ), โหมดหน้าต่างไร้กรอบ (3 สถานะ: หน้าต่าง/ขยายสูงสุด/เต็มหน้าจอ), ปุ่มวนสถานะหน้าต่าง, 17 คำสั่งไคลเอนต์ /aws, 5 ปุ่มลัดที่ปรับแต่งได้, รองรับหลายจอภาพ, แสดงความละเอียดแบบเรียลไทม์, โหมดบันทึกการดีบัก ฯลฯ รองรับ 20 ภาษา

【วิธีใช้】
1、หลังจากติดตั้ง mod และเปิดเกมแล้ว ให้คลิกปุ่ม "การจัดการหน้าต่างและการตั้งค่าความละเอียด" ใน "การตั้งค่าความสามารถในการเข้าถึง" เพื่อเปิดอินเทอร์เฟซการกำหนดค่า หรือใช้คำสั่ง /aws gui
2、ปรับการตั้งค่าต่างๆ ในอินเทอร์เฟซการกำหนดค่า: ขนาดหน้าต่าง, ล็อกขนาดขั้นต่ำ, ขนาดหน้าต่างคงที่, เต็มหน้าจอ/ขยายสูงสุด/ไร้กรอบอัตโนมัติ, หน้าต่างอยู่บนสุดเสมอ, โหมดไร้กรอบ ฯลฯ
3、ค่าล่วงหน้าความละเอียด: ใช้ลูกศรซ้าย/ขวาของตัวเลือกอัตราส่วนภาพเพื่อสลับระหว่าง 16:9, 16:10, 4:3, 5:4, 21:9, 3:2, 2:1, 9:16 และ กำหนดเอง ที่กึ่งกลางแสดงอัตราส่วนปัจจุบันและความละเอียดหน้าต่างแบบเรียลไทม์ และด้านล่างแสดงปุ่มค่าล่วงหน้า 16 ปุ่มสำหรับอัตราส่วนที่เกี่ยวข้อง คลิกเพื่อปรับขนาดหน้าต่างและจัดกึ่งกลางด้วยคลิกเดียว
4、ความละเอียดที่กำหนดเอง: หลังจากสลับไปที่อัตราส่วน "กำหนดเอง" ให้ป้อนความกว้างและความสูงในช่องป้อนข้อมูล คลิกปุ่ม "ใช้" หรือกดปุ่ม Enter ปุ่มใช้จะถูกปิดใช้งานพร้อมคำแนะนำเมื่อค่าที่ป้อนอยู่นอกช่วง
5、ปุ่มลัด: กำหนดปุ่มสำหรับ "เปิดการตั้งค่า Auto Window Size", "จัดกึ่งกลางหน้าต่าง", "สลับไร้กรอบ", "วนสถานะหน้าต่าง" และ "สลับหน้าต่างอยู่บนสุดเสมอ" ใน "การตั้งค่าการควบคุม" ไม่ได้กำหนดโดยค่าเริ่มต้น
6、คำสั่ง: พิมพ์ /aws help เพื่อดูรายการคำสั่งครบถ้วนแบบแบ่งหน้า (ทั้งหมด 3 หน้า, 8 คำสั่งต่อหน้า)
7、ไฟล์การกำหนดค่า: config/AutoWindowSize/config.toml (การกำหนดค่าหลัก) และ config/AutoWindowSize/window.json (ตำแหน่งหน้าต่างที่บันทึกไว้)

【คำสั่ง】
คำสั่งทั้งหมดขึ้นต้นด้วย /aws พิมพ์ /aws help ในเกมเพื่อดูรายการคำสั่งครบถ้วนแบบแบ่งหน้า
คำสั่งที่พบบ่อย:
· /aws help [หน้า] - แสดงรายการคำสั่ง (3 หน้า, 8 ต่อหน้า)
· /aws gui - เปิดอินเทอร์เฟซการจัดการหน้าต่างและการตั้งค่าความละเอียด
· /aws about - เปิดหน้าเกี่ยวกับ
· /aws info - แสดงข้อมูลหน้าต่าง การกำหนดค่า และความละเอียดปัจจุบัน
· /aws version - แสดงข้อมูลเวอร์ชันของ mod
· /aws config - เปิดโฟลเดอร์การกำหนดค่า
· /aws status - ตรวจสอบสถานะของล็อกขนาดขั้นต่ำ
· /aws toggle [true/false] - สลับล็อกขนาดขั้นต่ำ
· /aws fixed [true/false] - สลับขนาดหน้าต่างคงที่
· /aws center - จัดกึ่งกลางหน้าต่างบนจอภาพปัจจุบัน
· /aws fullscreen [true/false] - สลับสถานะเต็มหน้าจอปัจจุบัน
· /aws maximize [true/false] - สลับสถานะขยายสูงสุดปัจจุบัน
· /aws remember [true/false] - สลับหน่วยความจำตำแหน่งหน้าต่าง
· /aws top [off/normal/force] - วนหรือตั้งค่าโหมดอยู่บนสุดเสมอโดยตรง
· /aws debug [true/false] - สลับบันทึกการดีบัก
· /aws borderless [true/false] - สลับโหมดไร้กรอบ
· /aws borderless auto [true/false] - สลับโหมดไร้กรอบอัตโนมัติเมื่อเปิดตัว
· /aws resolution [อัตราส่วน] <ค่าล่วงหน้า> - ใช้ความละเอียดและจัดกึ่งกลาง รองรับการเติมข้อความอัตโนมัติด้วย Tab

【ปุ่มลัด】
ปุ่มลัดทั้งหมดไม่ได้ถูกกำหนดโดยค่าเริ่มต้น ตั้งค่าได้ที่ "ตัวเลือก → การควบคุม → Auto Window Size" เมื่อกดปุ่มลัดใดๆ จะมีการแสดงข้อเสนอแนะในแชต
· เปิดการตั้งค่า Auto Window Size - เปิดอินเทอร์เฟซการจัดการหน้าต่างและการตั้งค่าความละเอียด
· จัดกึ่งกลางหน้าต่าง - จัดกึ่งกลางหน้าต่างบนจอภาพปัจจุบัน
· สลับไร้กรอบ - เปิด/ปิดโหมดไร้กรอบ
· วนสถานะหน้าต่าง - วนระหว่าง หน้าต่าง → ขยายสูงสุด → เต็มหน้าจอ
· สลับหน้าต่างอยู่บนสุดเสมอ - วนโหมดอยู่บนสุดเสมอ (ปิด → มาตรฐาน → บังคับ)

【หมายเหตุ】
· การโยกย้ายการกำหนดค่าอัตโนมัติ: ตั้งแต่ v1.1.1 เมื่ออัปเดต mod จะตรวจจับและโยกย้ายไฟล์การกำหนดค่าเก่าโดยอัตโนมัติเมื่อเปิดตัวครั้งแรก คุณไม่จำเป็นต้องลบโฟลเดอร์การกำหนดค่าด้วยตนเอง หลังจากเข้าโลกแล้ว แชตจะแจ้งเตือนการโยกย้ายเสร็จสิ้น
· mod เฉพาะด้านไคลเอนต์: จำเป็นต้องติดตั้งเฉพาะบนไคลเอนต์เท่านั้น ไม่ใช่บนเซิร์ฟเวอร์
· การรองรับแพลตฟอร์ม: รองรับเฉพาะ Java Edition สำหรับเดสก์ท็อป (Windows / macOS / Linux) ไม่รองรับมือถือ / Bedrock Edition
· หน้าต่างไร้กรอบและ Windows Snap: ในเวอร์ชันปัจจุบัน ฟังก์ชัน Windows Snap (การยึดหน้าต่าง) อาจมีปัญหาความเข้ากันได้ในโหมดหน้าต่างไร้กรอบ วิธีแก้ไขชั่วคราว: ปิดใช้งานล็อกขนาดขั้นต่ำก่อน ใช้ Windows Snap เพื่อปรับหน้าต่าง จากนั้นเปิดใช้งานล็อกอีกครั้ง
· หมายเหตุเกี่ยวกับการอยู่บนสุดเสมอแบบบังคับ: โหมดบังคับจะอยู่บนสุดเสมอในหมู่หน้าต่างที่อยู่บนสุดเสมอในระดับเดียวกันและจะไม่ถูกปกคลุมโดยพวกมัน แต่จะไม่อยู่เหนือหน้าต่างที่อยู่บนสุดเสมอในระดับระบบ (เช่น ตัวจัดการงาน)
