Auto Window Size (Automatisk fönsterstorlek)

【Syfte】
När du gör en modpack lägger du mycket tid på att perfekt justera GUI:er, HUD:er och gränssnitt. Men när spelare startar spelet på olika skärmar eller upplösningar, ändras fönsterstorleken och alla layouter går sönder. Denna mod löser detta problem: den förvandlar "spelfönsterstorleken" från en slumpmässig händelse till ett kontrollerbart, reproducerbart och begränsat val. Dess omfattning är medvetet minimal — den fungerar bara med fönstret på operativsystemsnivå, ändrar inte GUI-skalan och rör inte någon in-game rendering eller spellogik, därför kommer den nästan aldrig i konflikt med andra mods.

【MOD-presenttion】
En lättviktig klient-side mod som automatiskt ändrar storlek, centrerar och låser Minecraft-spelfönstret, vilket håller dina noggrant justerade modpack UI-layouter konsekventa på varje spelares dator.
Huvudfunktioner: automatisk fönsterstorleksändring vid start, 128 upplösningsförinställningar (grupperade efter 8 bildförhållanden), låsning av minimal storlek, fast fönsterstorlek, centrering med ett klick, automatisk helskärm/maximera/gränslöst läge vid start, minne för fönsterposition, fönster alltid i förgrunden (3 lägen: av/standard/tvingat), gränslöst fönsterläge (3 tillstånd: fönster/maximerat/helskärm), fönstertillstånds-cyklusknapp, 17 /aws klientkommandon, 5 anpassningsbara kortkommandon, stöd för flera skärmar, realtidsupplösningsvisning, felsökningsloggläge, etc. Stöder 20 språk.

【Användning】
1、Efter att ha installerat modden och startat spelet, klicka på knappen "Fönsterhantering och upplösningsinställningar" i "Tillgänglighetsinställningar" för att öppna konfigurationsgränssnittet, eller använd kommandot /aws gui.
2、Justera olika inställningar i konfigurationsgränssnittet: fönsterstorlek, låsning av minimal storlek, fast fönsterstorlek, automatisk helskärm/maximera/gränslöst läge, fönster alltid i förgrunden, gränslöst läge, etc.
3、Upplösningsförinställningar: använd vänster/höger pilar på bildförhållandsväljaren för att växla mellan 16:9, 16:10, 4:3, 5:4, 21:9, 3:2, 2:1, 9:16 och Anpassat. I mitten visas aktuellt förhållande och realtidsfönsterupplösning, och nedan visas 16 förinställningsknappar för motsvarande förhållande. Klicka för att ändra fönsterstorlek och centrera med ett klick.
4、Anpassad upplösning: efter att ha växlat till förhållandet "Anpassat", ange bredd och höjd i inmatningsfälten, klicka på knappen "Använd" eller tryck på Enter-tangenten. Använd-knappen är inaktiverad med en tooltip när det inmatade värdet är utanför intervallet.
5、Kortkommandon: tilldela tangenter för "Öppna Auto Window Size-inställningar", "Centrera fönster", "Växla gränslöst", "Cykla fönstertillstånd" och "Växla fönster alltid i förgrunden" i "Kontrollinställningar". Ej tilldelade som standard.
6、Kommandon: skriv /aws help för att se den sidindelade fullständiga kommandolistan (totalt 3 sidor, 8 kommandon per sida).
7、Konfigurationsfiler: config/AutoWindowSize/config.toml (huvudkonfiguration) och config/AutoWindowSize/window.json (sparad fönsterposition).

【Kommandon】
Alla kommandon börjar med /aws. Skriv /aws help i spelet för att se den sidindelade fullständiga kommandolistan.
Vanliga kommandon:
· /aws help [sida] - Visa kommandolista (3 sidor, 8 per sida)
· /aws gui - Öppna fönsterhantering och upplösningsinställningar
· /aws about - Öppna Om-sidan
· /aws info - Visa aktuell information om fönster, konfiguration och upplösning
· /aws version - Visa modversionsinformation
· /aws config - Öppna konfigurationsmapp
· /aws status - Kontrollera status för minimal storlekslåsning
· /aws toggle [true/false] - Växla minimal storlekslåsning
· /aws fixed [true/false] - Växla fast fönsterstorlek
· /aws center - Centrera fönster på aktuell skärm
· /aws fullscreen [true/false] - Växla aktuellt helskärmstillstånd
· /aws maximize [true/false] - Växla aktuellt maximerat tillstånd
· /aws remember [true/false] - Växla minne för fönsterposition
· /aws top [off/normal/force] - Cykla eller ställ direkt in alltid-i-förgrunden-läge
· /aws debug [true/false] - Växla felsökningslogg
· /aws borderless [true/false] - Växla gränslöst läge
· /aws borderless auto [true/false] - Växla automatiskt gränslöst läge vid start
· /aws resolution [förhållande] <förinställning> - Använd upplösning och centrera, stöder Tab-auto komplettering

【Kortkommandon】
Alla kortkommandon är som standard ej tilldelade. Ställ in dem under "Alternativ → Kontroller → Auto Window Size". Vid tryck på vilket kortkommando som helst ges feedback i chatten.
· Öppna Auto Window Size-inställningar - Öppna fönsterhantering och upplösningsinställningar
· Centrera fönster - Centrera fönster på aktuell skärm
· Växla gränslöst - Växla gränslöst läge på/av
· Cykla fönstertillstånd - Cykla mellan fönster → maximerat → helskärm
· Växla fönster alltid i förgrunden - Cykla alltid-i-förgrunden-läge (av → standard → tvingat)

【Anmärkningar】
· Automatisk konfigurationsmigrering: från v1.1.1, vid uppdatering upptäcker och migrerar modden automatiskt gamla konfigurationsfiler vid första start. Du behöver inte manuellt ta bort konfigurationsmappen. Efter att ha gått in i en värld meddelar chatten slutförd migrering.
· Endast klient-side mod: behöver bara installeras på klienten, inte på servern.
· Plattformsstöd: stöder endast skrivbords Java Edition (Windows / macOS / Linux), stöder inte mobil / Bedrock Edition.
· Gränslöst fönster och Windows Snap: i nuvarande version kan Windows Snap (fönsterfästning) funktionen ha kompatibilitetsproblem i gränslöst fönsterläge. Tillfällig lösning: inaktivera först minimal storlekslåsning, använd Windows Snap för att justera fönstret och aktivera sedan låsningen igen.
· Anmärkning om tvingat alltid i förgrunden: det tvingade läget förblir alltid i förgrunden bland alltid-i-förgrunden-fönster på samma nivå och täcks inte av dem, men är inte högre än alltid-i-förgrunden-fönster på systemnivå (t.ex. Aktivitetshanteraren).
